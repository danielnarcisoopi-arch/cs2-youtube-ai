Skinshotter capture proof of concept

This patch adds an isolated, manually triggered GitHub Actions test. It does not
modify the scheduled Shorts workflow or publish a video.

1. Copy the files in this patch into the production repository, preserving paths.
2. Commit and push them to the repository's default branch.
3. Open GitHub Actions and run "Skinshotter capture proof of concept".
4. Leave the default AWP | Printstream URL for the first test, then start it.
5. Download the artifact named skinshotter-poc-<run id>.

The artifact should contain a 1080x1920, 10-second MP4, the raw WebM, before/after
screenshots, and a JSON report with HTTP, WebGPU, canvas and browser-error data.
If the run fails, the workflow still uploads the diagnostics.

The script tries to hide the viewer UI and presses F twice to request the CS
inspect animation. Review the MP4 and screenshots: Playwright cannot prove from
the exit code alone that the animation appeared in the rendered frames.

Local dependencies:
  python -m pip install -r scripts/requirements-skinshotter.txt
  python -m playwright install --with-deps chromium
  sudo apt-get install ffmpeg libvulkan1 mesa-vulkan-drivers

Local capture:
  python scripts/skinshotter_poc.py --url https://skinshotter.com/rifles/awp/printstream

The existing project archive is partial. Apply this patch over the full
production repository, not as a replacement for the complete project.
