CS2SCREEN capture proof of concept

This is a separate manual GitHub Actions workflow. It does not change the
scheduled Shorts job, market selection, or YouTube upload behavior.

1. Copy scripts/cs2screen_poc.py and .github/workflows/cs2screen-poc.yml into
   the full production repository.
2. Commit and push to the default branch.
3. In GitHub Actions, run "CS2SCREEN viewer capture proof of concept" and keep
   the default public demo URL for the first run.
4. Download artifact cs2screen-poc-<run id>.
5. Review cs2screen-vertical.mp4 and cs2screen-report.json. A successful job
   proves only that this hosted viewer rendered and was recordable in Actions;
   it does not prove Arena mode, catalog mode, audio, or account-specific
   features are enabled.

Local requirements:
  python -m pip install 'playwright>=1.59,<2'
  python -m playwright install --with-deps chromium
  sudo apt-get install ffmpeg libvulkan1 mesa-vulkan-drivers

Local capture:
  python scripts/cs2screen_poc.py --seconds 10

To test a different item, use its CS2SCREEN URL with the inspectlink query
parameter. The viewer URL must stay on https://3d.cs2screen.com/.

Important: the public demo uses the public demo key published by the provider.
Production integration requires the user's own viewer key and allowlisted
origin. The provider's pages currently differ in how they describe plan and
feature availability, so verify Arena/catalog entitlement in the account panel
before any purchase. No plan purchase or production integration is included.
